# Reference

The reference describes every part of Lore and the `lore` command, one page per element and per command. Use it to look things up; the [Guide](../guide/index.md) teaches the same material in order.

- [CLI](./cli/index.md): install, every command, every option, output formats and exit codes.
- [Errors and warnings](./errors.md): the names of the problems tools report.

For the normative rules every tool follows, see the [Specification](../spec/introduction.md).
